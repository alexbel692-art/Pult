# Штурвал

Своё удалённое управление компьютерами по локальной сети.

Работает по схеме Radmin: на каждом компьютере стоит **агент**, а на сервере — **консоль** со списком
компьютеров по офисам. Сторонние программы не нужны: всё написано на C# (.NET 8) и Windows API.

```
 Сервер (консоль Shturval.exe)                    Компьютер в офисе (ShturvalAgent.exe)
 ┌────────────────────────┐   TCP 5650,       ┌──────────────────────────────────────┐
 │ список ПК по офисам    │   AES-256-GCM     │ служба ShturvalAgent (SYSTEM, сессия 0)  │
 │ окно экрана, мышь,     │ ◄───────────────► │   └─ запускает помощника в сессии    │
 │ клавиатура, C+A+D      │                   │      пользователя: захват экрана,    │
 └────────────────────────┘                   │      ввод мыши и клавиатуры, плашка  │
                                              └──────────────────────────────────────┘
```

## Что умеет

- Просмотр и управление: мышь (вкл. колесо и боковые кнопки), клавиатура с раскладкой удалённого ПК.
- Работает и на экране входа/блокировки, и в окнах UAC (агент переключается на текущий рабочий стол).
- Ctrl+Alt+Del, кнопка Win, «Вставить текст» — набирает текст из буфера консоли на удалённом ПК.
- Все мониторы удалённого ПК одной картинкой, режим «по размеру окна» или 1:1 с прокруткой.
- Передаются только изменившиеся участки экрана (JPEG), качество — низкое/среднее/высокое.
- Список компьютеров с группами по офисам, проверка «в сети», поиск агентов в диапазоне адресов.
- Режим «только просмотр».
- Пока идёт подключение, у пользователя в углу экрана висит красная плашка
  «К компьютеру подключён администратор (IP)». Её можно отключить (`--no-banner`), но лучше оставить:
  сотрудники должны знать о подключении. Порядок удалённого доступа стоит закрепить внутренним регламентом.

## Безопасность

- Пароль по сети не передаётся. Агент и консоль доказывают друг другу, что знают пароль (HMAC-SHA256),
  дальше весь трафик шифруется AES-256-GCM с новыми ключами на каждую сессию.
- Агент хранит не пароль, а ключ из него (PBKDF2, 200 000 итераций), зашифрованный DPAPI.
  Папка `C:\ProgramData\Shturval` доступна только SYSTEM и администраторам.
- `--allow` ограничивает, с каких адресов можно подключаться. Это проверяет и сам агент,
  и правило брандмауэра Windows. **Указывайте IP сервера.**
- После 5 неверных паролей адрес блокируется на 5 минут.
- Пароль — не короче 8 символов, лучше 12+: перехватив рукопожатие, пароль можно подбирать офлайн.

## Сборка

Нужен .NET 8 SDK. Собирать можно на Mac (`./build.sh`) или на Windows (`build.cmd`).
Получатся два самостоятельных exe, .NET на компьютерах ставить не нужно:

- `out/agent/ShturvalAgent.exe` — агент для компьютеров;
- `out/viewer/Shturval.exe` — консоль для сервера.

## Установка агента на компьютер

**Проще всего:** запустите `ShturvalAgent.exe` двойным щелчком. Windows спросит права администратора,
откроется окно установки: задайте пароль, IP сервера с консолью и нажмите «Установить и запустить».
Агент встанет службой Windows с автозапуском: стартует сам при включении ПК, ещё до входа пользователя,
и перезапускается при сбое. Повторный запуск exe покажет состояние, позволит сменить настройки или удалить агент.

**Из командной строки** (например, для групповой политики):

От имени администратора:

```
ShturvalAgent.exe install --password "СложныйПароль123" --allow 192.168.1.10
```

| Параметр | Что делает |
|---|---|
| `--password` | пароль для подключения (обязательно при первой установке) |
| `--allow` | с каких адресов можно подключаться: `192.168.1.10` или `192.168.1.10,10.0.0.0/24` |
| `--port` | порт, по умолчанию 5650 |
| `--no-banner` | не показывать пользователю плашку о подключении |

Установщик копирует себя в `C:\Program Files\Shturval Agent`, создаёт службу `ShturvalAgent` (автозапуск,
перезапуск при сбое), правило брандмауэра и разрешение на Ctrl+Alt+Del.
Повторный `install` обновляет агента и настройки.

Остальные команды:

```
ShturvalAgent.exe setpass "НовыйПароль"     сменить пароль
ShturvalAgent.exe uninstall [--purge]       удалить (--purge — и настройки)
ShturvalAgent.exe debug                     запустить без службы, в текущей сессии (для проверки)
```

Лог агента: `C:\ProgramData\Shturval\agent.log`.

**На много компьютеров сразу** удобно через групповую политику: положить `ShturvalAgent.exe` в общую папку
и добавить скрипт автозагрузки компьютера с командой `install` выше.

## Консоль

Запустите `Shturval.exe` на сервере. «Найти в сети» проверит диапазон адресов и добавит всех найденных
агентов (можно сразу указать офис и общий пароль). Двойной щелчок — подключиться.
Список хранится в `%APPDATA%\Shturval\computers.json`, сохранённые пароли зашифрованы DPAPI вашей учётки.

В окне управления все клавиши уходят на удалённый ПК, включая Alt+F4. Закрыть окно — мышью.
Сочетания Win и Alt+Tab перехватывает ваша Windows, поэтому для Win есть кнопка на панели.

## Если офисы в разных сетях

Агенты слушают порт только в локальной сети. Чтобы сервер видел компьютеры других офисов,
сети офисов нужно связать VPN (site-to-site) и разрешить в `--allow` адрес сервера.

## Что можно добавить дальше

- Передача файлов и общий буфер обмена.
- Захват через DXGI Desktop Duplication — быстрее GDI и меньше нагрузка на процессор.

## Готовые сборки

Каждый push в `main` собирается в GitHub Actions, и exe сразу выкладываются в
**Releases → «Последняя сборка»** (тег `latest`).

Чтобы выпустить номерную версию, поставьте тег:

```
git tag v0.2.0 && git push origin v0.2.0
```
